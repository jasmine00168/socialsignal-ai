# SocialSignal AI

> 从社交媒体原帖中识别软件需求，保留逐字证据，并将相似需求聚类为可解释的产品机会。

SocialSignal AI 是一个面向产品经理、创业者和增长团队的 AI 需求研究工具。它将零散的社交表达转化为有来源、有结构、有评分依据的产品机会。

**当前版本：V0.2 · 已完成真实 OpenAI API 端到端验证**

## 产品解决什么问题

团队经常需要人工浏览大量社交内容、复制用户反馈并整理需求。这种方式速度慢、标准不一致，而且最终结论很难追溯到原文。

SocialSignal AI 的目标不是根据“热门程度”直接判断市场规模，而是：

1. 找到可能由软件解决的真实需求；
2. 提取用户、场景、痛点和期望方案；
3. 保存并校验原文证据；
4. 合并语义相似的需求；
5. 生成可解释的机会优先级。
